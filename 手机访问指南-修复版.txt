🎯 目标：让你的手机可以访问 IronTrader

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 第一步：安装 Ngrok（只需做一次）

1. 下载 Ngrok
   访问: https://ngrok.com/download
   下载 Windows 64-bit 版本

2. 解压文件
   解压到任意目录，比如: C:\ngrok\

3. 添加到 PATH（可选但推荐）
   - 右键"此电脑" -> 属性 -> 高级系统设置
   - 环境变量 -> 系统变量 -> Path -> 编辑
   - 新建 -> 输入 ngrok.exe 所在目录
   - 确定

   或者直接把 ngrok.exe 复制到 C:\Windows\System32\

4. 注册账号（免费）
   访问: https://dashboard.ngrok.com/signup
   用 Google 或 GitHub 账号快速注册

5. 获取 Token
   登录后访问: https://dashboard.ngrok.com/get-started/your-authtoken
   复制显示的 token（一长串字符）

6. 配置 Token
   打开命令提示符（Win+R，输入 cmd），运行:

   ngrok config add-authtoken 粘贴你的token

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🚀 第二步：启动服务（每次使用）

方法一：最简单（推荐）⭐
   双击运行: quick_start.bat

方法二：完整版（有检查）
   双击运行: start_public.bat

会弹出两个窗口：
   - "IronTrader-App" - 应用服务器
   - "Ngrok-Tunnel" - 公网隧道

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📱 第三步：获取公网地址

1. 查看 "Ngrok-Tunnel" 窗口
2. 找到这样的一行：

   Forwarding   https://1234-56-78-90-12.ngrok-free.app -> http://localhost:5002

3. 复制 HTTPS 地址（从 https:// 开始的那个）
4. 在手机浏览器打开这个地址

示例地址：
https://1234-56-78-90-12.ngrok-free.app

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📲 第四步：手机访问

打开手机浏览器，输入刚才复制的地址

可以访问的 API:
- 首页: https://your-url.ngrok-free.app/
- 市场状态: https://your-url.ngrok-free.app/api/market-state
- 涨停股: https://your-url.ngrok-free.app/api/hotzt
- 搜索: https://your-url.ngrok-free.app/api/search?q=平安

第一次访问可能会显示 "Visit Site" 按钮，点击继续即可

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🛑 停止服务

双击运行: stop_public.bat

或者直接关闭两个命令行窗口

💡 常见问题

Q: 双击 bat 文件后一闪而过？
A: 右键选择"编辑"查看错误，或在 cmd 中运行查看详细输出

Q: 提示找不到 ngrok？
A: 确保 ngrok.exe 在 PATH 中，或复制到 System32 目录

Q: 提示找不到 python？
A: 确保已安装 Python 并添加到 PATH

Q: 每次重启地址都变？
A: 免费版是这样的，可以考虑 Ngrok 付费版或 Cloudflare Tunnel

Q: 想在多台手机上访问？
A: 可以！同一个地址可以被多个设备访问
