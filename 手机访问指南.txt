🎯 目标：让你的手机可以访问 IronTrader

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 准备工作（只需做一次）

1. 下载 Ngrok
   访问：https://ngrok.com/download
   下载 Windows 版本并解压

2. 注册 Ngrok 账号（免费）
   访问：https://dashboard.ngrok.com/signup
   使用 Google/GitHub 账号快速注册

3. 获取 Token
   登录后访问：https://dashboard.ngrok.com/get-started/your-authtoken
   复制你的 authtoken（一长串字符）

4. 配置 Token（在 PowerShell 中运行）
   ngrok config add-authtoken 你的token

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🚀 每次使用（超简单）

方法一：一键启动（推荐）⭐
   1. 双击运行 start_public.ps1
   2. 等待几秒
   3. 查看 Ngrok 窗口，复制 "Forwarding" 行的 HTTPS 地址
   4. 手机浏览器访问该地址

方法二：手动启动
   1. 打开 PowerShell，运行：python app.py
   2. 再打开一个 PowerShell，运行：ngrok http 5002
   3. 查看 Ngrok 窗口，复制 HTTPS 地址
   4. 手机浏览器访问该地址

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

https://a1b2-34-56-78-90.ngrok-free.app

在手机浏览器输入这个地址就能访问！

方法一：双击运行 stop_public.ps1
方法二：关闭所有打开的 PowerShell 窗口

💡 常见问题

Q：每次重启地址都变？
A：免费版是这样的，付费版可以固定域名。
   或者使用 Cloudflare Tunnel（免费且固定）

Q：手机访问提示 "Visit Site"？
A：这是 Ngrok 的防滥用机制，点击继续即可（只需点一次）

Q：想要固定的域名？
A：推荐使用 Cloudflare Tunnel（免费）
   或升级 Ngrok 付费版

Q：担心安全问题？
A：可以添加密码保护，详见 PUBLIC_ACCESS_README.md
